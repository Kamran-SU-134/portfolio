# Kamran Khan - Cybersecurity Portfolio

A static, responsive portfolio built with separate HTML, CSS, and vanilla JavaScript files. It has no backend, build step, or required external dependencies.

## Project files
- `index.html` — page structure and content
- `style.css` — colors, layout, responsive styling, and visual effects
- `script.js` — mobile navigation, current year, placeholder-link notice, and active navigation highlighting

## Preview locally
Keep all three files in the same folder, then open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `kamran-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Before publishing
Replace the following placeholders in `index.html`:
- `[Add your email address]`
- `[Add your phone number]`
- `[Add GitHub profile URL]`
- `[Add LinkedIn profile URL]`
- Certificate placeholders under Certifications & Achievements
- Add only verified CTF challenges, achievements, and certificate details.

Project statuses are intentionally labelled as **In development** or **Concept / research** based on the supplied information. Add findings only after testing and validation.
